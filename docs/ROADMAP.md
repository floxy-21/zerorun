# Public roadmap

The next objective is external proof, not broader claims.

1. Run 100 real external agent or CI requests inside the supported boundary.
2. Complete several design-partner workloads and publish measured hit, miss,
   bypass, verification, p95, and compute results.
3. Distinguish and measure three separate 5x questions: wall speed, compute
   efficiency, and customer value relative to price.
4. Validate buyer ownership, willingness to pay, retention, and paid pilots.
5. Review the runtime for a deliberate source release: secrets, license/IP,
   dependency provenance, reproducible evidence, and security documentation.

Roadmap items are intentions, not commitments or completed milestones.
