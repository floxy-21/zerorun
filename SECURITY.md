# Security

Please do not disclose a suspected vulnerability in a public issue.

Email `kapoorjishan2@gmail.com` with the subject `ZeroRun security report` and
include a concise description, affected surface, reproduction steps, and impact.
Do not include credentials, private keys, access tokens, or unrelated sensitive
data.

This public repository currently documents the product and its supported
boundary. It is not a public release of the ZeroRun runtime implementation.
